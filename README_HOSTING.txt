LEG 49 AUTHORING CHANGES

1. GEOGRAPHIC STORY CLUSTERS
Stories about the same place are kept together while that place is visually relevant.
The script does not split one town or landmark merely to distribute narration across miles.

2. GEOGRAPHIC ORDER FIRST
Narration follows the actual sequence of the flight. One location's stories are completed
before the guide moves on to the next location unless there is a natural geographic reason
to return to an earlier subject.

3. NO DEVELOPMENT META-LANGUAGE IN SPOKEN NARRATION
The finished tour contains no references to route-generation software, route testing,
viewing-pass algorithms, or development decisions. Viewing directions are simply stated
naturally to the pilot.

4. MORE CONVERSATIONAL QUIET-STRETCH BRIDGES
The automatic sign-offs now use nine less formal variants. Most avoid exact mileage/time
and sound more like a companion choosing to stay quiet for a while.

5. VIEWING-PASS AWARE
Priest Rapids Dam and the broad Columbia are described as west of the track.
Hanford Reach is described from the east-bank side.
The narrator never assumes a named sight is directly underneath a waypoint.
